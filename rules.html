  1. 1.🟦 The game is played on a 3×3 grid.
  2. 2.✖️⭕ Two players take turns: one is X, the other is O.
  3. 3.🚫 Players can place their mark only in an empty cell.
  4. 4.🏆 The first player to get three in a row (horizontal, vertical, or diagonal) wins.
  5. 5.🤝 If all cells are filled with no winner, the game ends in a draw.
